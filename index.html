API Documentation

Integrasi REST API untuk pembuatan tagihan QRIS dinamis otomatis dan pelacakan mutasi realtime.

⚡

The Basics

Gunakan REST API GoPay Bill untuk membuat tagihan QRIS dinamis otomatis, mengecek status pembayaran secara realtime, dan mengelola transaksi secara programmatic. Semua endpoint terlindungi menggunakan autentikasi Kunci Rahasia (API Key).

BASE URL
https://apis.buzzel.dpdns.org/api
API KEY • PROFIL: —
Autentikasi: Sertakan header HTTP X-API-Key: <key> atau Authorization: Bearer <key>. Request programmatic dengan API Key valid otomatis diizinkan tanpa batasan IP whitelist.
Isolasi Saldo & Akun GoPay: Setiap profil merchant terhubung secara mandiri ke akun GoPay Merchant dan QRIS masing-masing. API Key Anda hanya terhubung ke toko Anda. Semua dana pembayaran tagihan dari API ini 100% langsung masuk ke saldo GoPay Merchant Anda sendiri, bukan ke akun pengembang atau profil lain.

QRIS Dinamis Otomatis

Generate QRIS instan dengan nominal pesanan spesifik. Kompatibel dengan semua aplikasi e-wallet & mobile banking di Indonesia.

Pelacakan Mutasi Realtime

Sistem memonitor mutasi masuk secara otomatis dan memperbarui status tagihan menjadi paid tanpa perlu polling berlebihan.

Multi Bahasa & SDK

Contoh integrasi siap pakai untuk cURL, Node.js / JavaScript Fetch, dan Python Requests dengan API Key yang langsung terpasang.

POST https://apis.buzzel.dpdns.org/api/bills

Membuat tagihan baru dengan nominal tertentu dan menghasilkan kode QRIS dinamis (string QR dan SVG) siap dipajang ke pembeli.

Prasyarat: Pastikan Anda telah menghubungkan akun GoPay Merchant via OTP dan mengisi payload QRIS statis di profil dashboard Anda agar QRIS dinamis dapat dibuat dan dana masuk ke rekening Anda.
